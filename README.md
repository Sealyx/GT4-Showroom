# GTA SA Scripts

Gameplay scripts for classic GTA San Andreas PC.

## GT4 Showroom

[GT4 Showroom](GT4Showroom/README.md) is a Gran Turismo4-inspired animated
vehicle showroom and spawner, with installed/add-on vehicles, colors/liveries,
Favorites, country filters, cinematic orbit and keyboard/mouse/controller controls.

- [Download2.2.0 complete package](https://github.com/Sealyx/GTA-SA-Scripts/releases/download/gt4-v2.2.0/GT4Showroom-ASI-v2.2.0.zip)
- [Installation and controls](GT4Showroom/README.md)
- [Source and build instructions](GT4Showroom/BUILD.md)
- [Validation and game-test scope](GT4Showroom/TEST-RESULTS.md)

Requires classic GTA SA1.0 US Hoodlum/Compact32-bit, a working32-bit ASI loader
and the included assets. This is a standalone ASI; CLEO/MoonLoader/ImGui are not
required.2.2.0 is a new controller-polish build awaiting an in-game retest.

Each script keeps its own folder and dependency notices. Other projects are not
included in this repository yet.
