FAQ:

1. Nothing pops up when I press F4

Then you either haven't installed ASI Loader or not running the correct build of the game (HOODLUM/Compact US 1.0).
Make sure you have installed all versions of Microsoft Visual C++ (2005-2022) as well.

2. Is this vibecoded?

I get that nowadays it's easy to assume anything is generated by AI but no it's not. I only used ChatGPT as my main assist
to learn C++ around late 2024 to early 2025, this was when I started to experiment with coding and make something for GTA for testing.

At first it was challenging, I didn't want to show anything back then cause I was genuinely terrible at it. 
I only did make one car spawner with some GT4 assets I've been given (they're mostly just sound effects & music), 
it has the same kind of 3D preview from this mod but I can never get the texture of the cars to look right in the preview, 
they do spawn but the preview is what's bugging me until around October 2025.

I revisited the project again, learning again. It's only around November-December I got something close 
to what I wanted but not quite right, this is when my dad told me about Claude how it's helpful to help me 
if I have any issues with my coding. Claude revised some of my codes, it was mostly just to fix the performance.
I rewrote and rephrased all the codes that Claude supervised, then I put it in the script myself. 

It's only after July 2026 I revisited this project and try to finish it slowly. Making the designs, applying more sound effects,
learn how to animate small UI elements, getting VehFuncs & IVF cars to look right and so on. 
And only just around early October 2026 I can finally show something.

3. Why a spawner and not a car dealership system?

Because I wanted a spawner first, I learned to make a car spawner not a car dealersip system and
I don't want to start from scratch. There is already a Car Dealer script from rill_ basically has the same premise
as I would've imagined this can turn out to be if I had a different idea.

4. Do you have any more ideas for future scripts?

There are 2 smaller ones almost finished but they're not fully ready yet. 
I only started doing them just this July for experiment in other categories.
But there is one massive project I really want to continue but it's just a really small code draft at the moment.
It's a tuning system expansion inspired by Need for Speed Underground 2.
