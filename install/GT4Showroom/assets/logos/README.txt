Optional per-vehicle logos

Switch Car and Manufacturer independently in the showroom sidebar or [Logos]. Both default to0.
Each folder uses the exact original internal vehicle model name. Add a folder with the exact internal name for an add-on.
car.png = vehicle name wordmark; brand.png = manufacturer. Either file can be omitted independently.
Use transparent PNGs for best integration. The supplied Grotti sample is preserved byte-for-byte.
GTSPAWN reloads logo files. Never name a PNG with a model ID.
