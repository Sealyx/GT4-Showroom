# REALBIG1.9 implementation sources and limits

The user1.8.1 log records11/11 upgrades ready, then paintjob timeout for Elegy/Stratum. This distinguishes the failing stage from the earlier log's unknown asset. Matching local gta-reversed Streaming.cpp ConvertBufferToObject rejects a standalone TXD when neither IsRequiredToBeKept nor AreTexturesUsedByRequestedModels holds. Flags0 triggered that gate. RequestTxdModel0x407100 now receives KEEP_IN_MEMORY8; CTxdStore AddRef0x731A00/RemoveRefWithoutDelete0x731A70 balance the preparation lease. Native loaded-list behavior allows ordinary eviction after references end. We do not set a permanent game/mission-required flag.

Native metadata: CVehicleModelInfo upgrades+0x2D6[18], remaps+0x2FA[4], wheelClass+0x4F; CAtomicModelInfo flags+0x12, common-dictionary bit15, dummy bit8 and slot bits10..14. Native wheel count0x4C8740 and getter0x4C8750 return int; older plugin-sdk incorrectly declares the getter void, so the matching reversed implementation/disassembly is the ABI reference. Native linked upgrade request/readiness handle paired parts. FLA GetExtendedIDfrom16bitBefore is used for registered extended IDs when exported. Full custom frameworks not represented in this metadata need a separate adapter.

Ability ownership: CPools GetVehicleRef0x54FFC0/GetVehicle0x54FFF0, vehicle handling pointer+0x384, physical mass+0x8C/turn+0x90/buoyancy+0xA0 and heavy bit0 at+0x40. Private handling copy follows the live validated stride; fields+4/+8/+12/+36 are mass/inverse mass/turn/buoyancy. Proof mask0x00840000 covers bullet and explosion only. The older one-shot helper remains a legacy unit fixture; production uses the maintained registry. DebugCode0x6A2F80 demonstrates that engine code can rewrite mass from handling, but static analysis found no direct calls in this executable, so it is not asserted as the proven cause of the user's ability report. Readback is now logged; no native damage/physics test was run.

Studio: real mesh files, not a screenshot projection. Extruded Great Vibes lettering, folded curtain and floor were created by the included Blender script. Local coordinates follow Camera.origin at100km from SA and do not spawn an IPL/teleport CJ. Lighting moves, cloth is static geometry. Renderer/state/viewport tests are separate from a GTA test.
