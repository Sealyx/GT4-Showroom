# Country assignments — 1.8.0

All 212 vanilla IDs 400–611 are assigned. These are inferences from each **San Andreas design's dominant real donor**, not official Rockstar nationalities or brands from other GTA games. Infernus uses the SA Honda NSX reference (Japan); Comet is Porsche-derived (Germany); Rumpo is Fiat Ducato-derived (Italy); Dune is Kamaz-derived (Russia). Source descriptions and alternatives travel with every row in country-origins.csv/json.

Country totals: {'USA': 161, 'Germany': 8, 'Japan': 26, 'Italy': 6, 'Canada': 2, 'Australia': 1, 'France': 1, 'Denmark': 1, 'UK': 5, 'Russia': 1}. Assignment bases: {'dominant donor inference': 159, 'donor': 25, 'regional design-family fallback (no unique production donor established)': 16, 'design-family inference': 10, 'family variant': 2}. Generic trailers, RC/toy/generic marine equipment with no distinct production donor use explicit regional design-family fallbacks. They are not falsely presented as manufacturer-confirmed donors. No stock slot is left white. For multi-donor cars, the selected dominant inspiration is explicit; evidence can differ on lesser details.

Reference catalogue: https://gta.fandom.com/wiki/Vehicles_in_GTA_San_Andreas ; SA-specific descriptions: https://www.gtabase.com/gta-san-andreas/vehicles/ . Each CSV row links its exact source page. GTA Wiki/IGCD design pages resolve selected disagreements. The source collection obtained 161 SA-specific donor descriptions from GTABase; remaining entries use listed vehicle/family references. Model IDs were cross-checked against the installed vehicles.ide and https://wiki.multitheftauto.com/wiki/Vehicle_IDs . Research date: 2026-10-18.

**INI is for add-ons only.** IDs 400–611 always return their built-in assignment before any override is read, even when a replacement uses that slot. Listing vanilla IDs or their names in Countries cannot change them. For add-ons, explicit IDs precede internal/display-name matches, case-insensitive; among conflicting same-kind rules, the documented country order wins. Use one group per add-on. No Unknown key is parsed. A missing add-on mapping produces the pure white inner badge, serving as a missing-configuration indicator. Unknown is only an internal enum for that state.

Supported keys: USA, Japan, Italy, France, UK, Germany, Sweden, China, SouthKorea, Canada, Australia, Russia, Denmark. GTSPAWN/reopening reloads them. White has no INI assignment. Original procedural flag artwork follows the circular black/silver style; it is not claimed as a GT4 rip. Japan's red center is smaller than the early draft.
